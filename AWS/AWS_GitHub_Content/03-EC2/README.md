## Before launching an instance

1. Select the correct Region.
2. Choose an appropriate AMI and instance type.
3. Configure a key pair or another supported access method.
4. Configure a security group with only the required inbound traffic.
5. Review storage and networking settings.
6. Check the estimated cost and current Free Tier eligibility.
