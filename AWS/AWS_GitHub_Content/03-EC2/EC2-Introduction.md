# EC2 – Introduction

## What is Amazon EC2?

Amazon Elastic Compute Cloud (EC2) is an AWS service for launching and managing virtual servers in the cloud.

## Main features

- **Scalability:** Change capacity to match workload requirements.
- **Instance choices:** Select compute, memory, storage, and networking characteristics.
- **Secure access:** Use key pairs, security groups, and appropriate identity controls.
- **Flexible purchasing:** Choose among options such as On-Demand, Spot, and commitment-based pricing.

## Common use cases

- Hosting websites and web applications
- Running batch processing jobs
- Development and testing
- Application and database workloads

## Important EC2 terms

| Term | Meaning |
|---|---|
| Instance | A virtual server |
| AMI | A template used to launch an instance |
| Instance type | Defines the instance's hardware capacity |
| Key pair | Credentials used for supported instance login methods |
| Security group | Virtual firewall for instance network traffic |
| EBS | Block storage commonly attached to EC2 |

## Practical task

Open the EC2 service in the AWS Console. Identify the Instances, AMIs, Instance Types, Key Pairs, Security Groups, and Volumes sections.
