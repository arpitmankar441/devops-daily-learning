## How to study

- Read the concept first.
- Follow the practical steps in your own AWS account.
- Record command output and screenshots where appropriate.
- Complete the assignment after each module.

## Cost and security reminder

AWS resources can incur charges. Check current AWS pricing and Free Tier eligibility before launching resources. Create billing alerts, restrict inbound access to your own IP where possible, and delete resources when finished.
